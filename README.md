# Конфигурация проекта
## "Код рулит" - интерактивный тренажёр программирования с транспортными маршрутами.
## Описание
"Код рулит" — мобильное PWA приложение, предназначенное для изучения основ алгоритмического мышления, циклов и условных операторов.
Обучение происходит в формате 2D-игры, в которой пользователь при помощи простых команд, условий и циклов, должен управлять транспортным средством, выполняя при этом различные задания.
## Идея
Научиться программировать через управление транспортом с помощью собственных алгоритмов
## Цель
Создать интерактивный мобильный тренажёр, который позволит пользователям в игровой форме освоить базовые принципы построения алгоритмов и практическое применение условных операторов и циклов.

## Целевая аудитория
Проект нацелен преимущественно на подростков в возрасте от 12 до 17 лет и новичков в программировании.
## Геймплей
Игровой процесс строится вокруг прохождения отдельных уровней. На каждом уровне игроку даётся конкретный транспорт - такси, автобус, грузовик. Игрок должен составить алгоритм, состоящий из простых команд, условий и циклов, который переместит транспорт в нужную точку.
При этом игрок должен выполнить определённые задания.
Примеры заданий:
- доставить пассажира в нужное место;
- подобрать нескольких пассажиров;
- перевезти груз между точками;
- проехать через заданные контрольные точки;
- объехать препятствие;
- выбрать маршрут в зависимости от состояния трафика;
Если программа содержит ошибку, пользователь видит её последствия непосредственно в игре. Например, транспорт может повернуть не в том направлении, столкнуться с препятствием или не выполнить необходимое условие.
## Механика игры
Основная игровая механика основана на связи программного алгоритма с движением транспортного средства.
Для написания алгоритма используется простейший язык программирования, собственной разработки.
### Доступны следующие команды:
- вперёд (движение вперёд);
- назад (движение назад);
- вправо (поворот вправо);
- влево (поворот влево);
- загрузить (впустить пассажиров / подобрать груз)
- выгрузить (выпустить пассажиров / разгрузиться)
#### Условия:
- спереди_свободно,
- снизу_свободно,
- справа_свободно,
- слева_свободно,
#### Логические операции:
- и (конъюнкция),
- или (дизъюнкция),
- не (отрицание),
#### Условные конструкции и циклы:
- если <условие>: <код>,
- если <условие>: <код> иначе: <код>,
- пока <условие> выполнить <код> конец,
- повторить n раз: <код>,
### Пример программы
~~~
если спереди_свободно:
вперёд иначе:
загрузить
~~~
Для сложных уровней пользователь сможет комбинировать несколько конструкций, например использовать условие внутри цикла.
## Система обучения
Сначала игрок решает простые задачи с последовательным выполнением команд. Затем в игру постепенно вводятся условные операторы и циклы.
#### Этапы обучения:
1. Основы управления транспортом.
2. Последовательность команд.
3. Условные операторы.
5. Циклы.
6. Комбинирование циклов и условий.
7. Комплексные алгоритмические задачи.
Каждая новая конструкция сначала объясняется на простом уровне, после чего пользователь применяет её самостоятельно в игровой ситуации.
Для анализа алгоритма предусматривается пошаговый режим. При его использовании приложение показывает, какая команда выполняется в текущий момент, и одновременно отображает действие транспорта на карте.
### Задачи
1) Подготовить ресурсы для проекта (иконки, текстуры).
2) Разработать интерфейс мобильного приложения.
3) Разработать игру и интегрировать её в приложение.
4) Разработать систему обучения.
5) Реализовать сохранение данных пользователя.
6) Добавить уроки в курс обучения.
7) Реализовать хостинг PWA-приложения.
### Технологии
- Vue и JS для фронта.
- Python библиотека Flask для бэкэнда PWA-приложения.
## Заключение
**"Код Рулит"** - объединяет мобильное обучение, игровую механику и программирование. Основная направленность проекта — сделать изучение циклов, условий и алгоритмов наглядным и практическим.
Игровой мир выступает визуальной средой выполнения программы, а транспортное средство — исполнителем алгоритма. Благодаря этому пользователь не только изучает синтаксические конструкции, но и понимает их практическое назначение через наблюдаемый результат.
