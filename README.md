# "КодРулит" - интерактивный тренажёр программирования с транспортными маршрутами.
## Описание
"КодРулит" — мобильное PWA приложение, предназначенное для изучения основ алгоритмического мышления, циклов и условных операторов.
Обучение происходит в формате 2D-игры, в которой пользователь при помощи простых команд, условий и циклов, должен управлять транспортным средством, выполняя при этом различные задания.
## Идея
Научиться программировать через управление транспортом с помощью собственных алгоритмов
## Цель
Создать интерактивный мобильный тренажёр, который позволит пользователям в игровой форме освоить базовые принципы построения алгоритмов и практическое применение условных операторов и циклов.
## Целевая аудитория
Проект нацелен преимущественно на подростков в возрасте от 12 до 17 лет и новичков в программировании.
## Геймплей
Игровой процесс строится вокруг прохождения отдельных уровней. На каждом уровне игроку даётся конкретный транспорт - такси, автобус, грузовик. Игрок должен составить алгоритм, состоящий из простых команд, условий и циклов, который переместит транспорт в нужную точку. Если программа содержит ошибку, пользователь видит её последствия непосредственно в игре. Например, транспорт может повернуть не в том направлении, столкнуться с препятствием или не выполнить необходимое условие.
## Механика игры
Основная игровая механика основана на связи программного алгоритма с движением транспортного средства.
Для написания алгоритма используется простейший язык программирования, собственной разработки.
### Доступны следующие команды:
- вперёд (движение вперёд);
- вправо (поворот вправо);
- влево (поворот влево);
#### Условия:
- спереди_свободно;
- справа_свободно;
- слева_свободно;
#### Условные конструкции и циклы:
- повторить n раз: <код>ж
- если <условие>: <код>;
- пока <условие> <код> конец;
## Система обучения
Сначала игрок решает простые задачи с последовательным выполнением команд. Затем в игру постепенно вводятся условные операторы и циклы.
#### Этапы обучения:
1. Основы управления транспортом.
2. Циклы.
3. Условные операторы.
4. Условные циклы
Каждая новая конструкция сначала объясняется на простом уровне, после чего пользователь применяет её самостоятельно в игровой ситуации.
Для анализа алгоритма предусматривается пошаговый режим. При его использовании приложение показывает, какая команда выполняется в текущий момент, и одновременно отображает действие транспорта на карте.
## Задачи
1) Подготовить ресурсы для проекта (иконки, текстуры).
2) Разработать интерфейс мобильного приложения.
3) Разработать игру и интегрировать её в приложение.
4) Разработать систему обучения.
5) Реализовать сохранение данных пользователя.
6) Добавить уроки в курс обучения.
7) Реализовать хостинг PWA-приложения.
## Технологии
Наше приложение представляет собой PWA, созданное через веб-технологии HTML, CSS, JS. Для реализации игровой механики используется фреймворк Alpine.js, а для стилизации - daisyUI.
## Заключение
**"КодРулит"** - объединяет мобильное обучение, игровую механику и программирование. Основная направленность проекта — сделать изучение циклов, условий и алгоритмов наглядным и практическим.
Игровой мир выступает визуальной средой выполнения программы, а транспортное средство — исполнителем алгоритма. Благодаря этому пользователь не только изучает синтаксические конструкции, но и понимает их практическое назначение через наблюдаемый результат.
## Локальный запуск
1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/pokedimon/CodeRulit.git
   cd CodeRulit
   ```
2. **Запустите локальный сервер (любым удобным способом):**
   - **Через Python 3:**
     ```bash
     python -m http.server 8000
     ```
   - **Через Node.js / npx:**
     ```bash
     npx serve .
     ```
   - **Через VS Code:** установите расширение *Live Server* и нажмите **Go Live**.
3. **Откройте приложение в браузере:**
   Перейдите по адресу `http://localhost:8000` (или порту, указанному сервером).
