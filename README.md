# Конфигурация проекта

## Название

**TransProger** — интерактивный тренажёр программирования с транспортными маршрутами.

## Описание

TransProger — мобильное обучающее приложение в формате 2D-игры, предназначенное для изучения основ алгоритмического мышления, циклов и условных операторов.

Пользователь управляет транспортным средством — такси, автобусом или грузовиком — с помощью алгоритма, который он самостоятельно составляет. Транспорт должен выполнять поставленную задачу: перевозить пассажиров или груз, посещать контрольные точки, объезжать препятствия и достигать пункта назначения.

Основная идея проекта заключается в визуальном представлении программных конструкций через игровую ситуацию: пользователь пишет алгоритм, запускает его и сразу видит результат его выполнения на игровой карте.

## Цель

Создать интерактивный мобильный тренажёр, который позволит пользователям в игровой форме освоить базовые принципы алгоритмического мышления и практическое применение условных операторов и циклов.

## Задачи

1. Разработать 2D-игровое пространство с дорогами, перекрёстками, препятствиями и объектами взаимодействия.
2. Реализовать несколько видов транспорта с различными типами заданий.
3. Создать систему составления алгоритмов из доступных программных команд.
4. Реализовать поддержку условных операторов и циклов.
5. Реализовать выполнение алгоритма и визуальное отображение его результата.
6. Добавить пошаговый режим выполнения программы для анализа действий транспорта.
7. Создать систему уровней с постепенным увеличением сложности.
8. Реализовать обратную связь при ошибках и неудачном выполнении алгоритма.
9. Добавить систему оценки прохождения уровней и игровых достижений.
10. Сформировать последовательный обучающий курс от простых последовательностей команд до комбинирования циклов и условий.

## Целевая аудитория

Основная целевая аудитория — начинающие пользователи, изучающие основы программирования и алгоритмического мышления.

Приложение ориентировано преимущественно на:

- школьников и подростков, изучающих информатику;
- пользователей, которые впервые знакомятся с программированием;
- учащихся, которым требуется дополнительная практика по теме алгоритмов;
- преподавателей, использующих интерактивные инструменты для обучения основам программирования.

## Геймплей

Игровой процесс строится вокруг прохождения отдельных уровней. На каждом уровне пользователь получает транспортное средство и конкретную задачу.

Примеры заданий:

- доставить пассажира в нужное место;
- подобрать нескольких пассажиров;
- перевезти груз между точками;
- проехать через заданные контрольные точки;
- объехать препятствие;
- выбрать маршрут в зависимости от состояния дороги;
- повторить определённое действие необходимое количество раз.

Перед запуском уровня пользователь составляет программу из доступных команд. После запуска транспорт начинает выполнять созданный алгоритм на игровой карте.

Если программа содержит ошибку, пользователь видит её последствия непосредственно в игре. Например, транспорт может повернуть не в том направлении, столкнуться с препятствием или не выполнить необходимое условие.

## Механика игры

Основная игровая механика основана на связи программного алгоритма с движением транспортного средства.

Пользователь получает набор команд, например:

- движение вперёд;
- поворот налево;
- поворот направо;
- остановка;
- проверка наличия препятствия;
- проверка состояния дороги;
- условие `если / иначе`;
- повторение команды или группы команд.

Сначала игрок решает простые задачи с последовательным выполнением команд. Затем в игру постепенно вводятся условные операторы и циклы.

Например:

**Если дорога свободна — двигаться вперёд, иначе — повернуть направо.**

Или:

**Повторять движение вперёд, пока транспорт не достигнет пункта назначения.**

Для сложных уровней пользователь сможет комбинировать несколько конструкций, например использовать условие внутри цикла.

### Система обучения

Обучение разделяется на последовательные этапы:

1. Основы управления транспортом.
2. Последовательность команд.
3. Условные операторы.
4. Простые циклы.
5. Циклы с условиями.
6. Комбинирование циклов и условий.
7. Комплексные алгоритмические задачи.

Каждая новая конструкция сначала объясняется на простом уровне, после чего пользователь применяет её самостоятельно в игровой ситуации.

### Пошаговое выполнение

Для анализа алгоритма предусматривается пошаговый режим. При его использовании приложение показывает, какая команда выполняется в текущий момент, и одновременно отображает действие транспорта на карте.

Это позволяет пользователю увидеть прямую связь между программой и её результатом:

**команда → действие транспорта → изменение состояния игровой карты.**

### Система оценки

После завершения уровня приложение может оценивать результат по нескольким параметрам:

- выполнено ли задание;
- количество использованных команд;
- количество ошибок;
- количество попыток;
- длина маршрута;
- эффективность созданного алгоритма.

Оценка используется как средство обратной связи и помогает пользователю анализировать собственное решение.

## Общая концепция проекта

TransProger объединяет мобильное обучение, игровую механику и визуальное программирование. Основная направленность проекта — сделать изучение циклов, условий и алгоритмов наглядным и практическим.

Игровой мир выступает визуальной средой выполнения программы, а транспортное средство — исполнителем алгоритма. Благодаря этому пользователь не только изучает синтаксические конструкции, но и понимает их практическое назначение через наблюдаемый результат.

Целевая идея проекта:

> **Научиться программировать через управление транспортом с помощью собственных алгоритмов.**
