# Конфигурация проекта
## «КодРулит» — интерактивный тренажёр программирования с транспортными маршрутами

## Описание
«КодРулит» — мобильное PWA-приложение, предназначенное для изучения основ алгоритмического мышления, циклов и условных конструкций.
Обучение происходит в формате 2D-игры, в которой пользователь при помощи простых команд, условий и циклов управляет транспортным средством, выполняя различные задачи на карте города.

## Идея
Научиться программировать через управление умным транспортом с помощью собственных алгоритмов.

## Цель
Создать интерактивный мобильный тренажёр, который позволит пользователям в игровой форме освоить базовые принципы построения алгоритмов и практическое применение условных операторов и циклов.

## Целевая аудитория
Проект нацелен преимущественно на подростков в возрасте от 12 до 17 лет и всех начинающих изучать программирование.

## Геймплей
Игровой процесс строится вокруг прохождения отдельных уровней. Игрок управляет городским транспортом и составляет алгоритм из простых команд, условий и циклов, который безопасно перемещает машину к цели.

Примеры заданий:
- проехать по заданному маршруту до финиша;
- объехать дорожные препятствия и тупики;
- автоматизировать движение по длинной улице с помощью циклов;
- выбрать безопасный поворот по сигналам бортовых датчиков.

Если программа содержит ошибку, пользователь сразу видит её последствия: автомобиль может свернуть не туда или врезаться в преграду. Предусмотрены подсказки и советы встроенного ИИ-Штурмана.

## Механика игры
Основная игровая механика основана на связи программного алгоритма с движением транспортного средства по сетке перекрёстков.
Для написания алгоритма используется простой и наглядный учебный синтаксис на русском языке.

### Доступные команды:
- `вперед` (шаг вперёд по направлению движения);
- `направо` (поворот на 90° по часовой стрелке);
- `налево` (поворот на 90° против часовой стрелки).

#### Сенсоры пространства (условия):
- `спереди_свободно` (впереди нет препятствия или края карты);
- `справа_свободно` (полоса справа свободна для поворота);
- `слева_свободно` (полоса слева свободна для поворота).

#### Условные конструкции и циклы:
- `если <условие> то: <код>`
- `пока <условие> выполнить: <код>`
- `повторить <n> раз: <код>`

### Пример программы
```python
пока спереди_свободно выполнить:
    вперед
    если справа_свободно то:
        направо
```

## Система обучения
Сначала игрок осваивает базовое последовательное выполнение команд (линейные алгоритмы). Затем постепенно вводятся циклы, проверки датчиков и их комбинации.

#### Этапы обучения:
1. Основы движения: первый выезд и повороты.
2. Циклические маршруты (`повторить N раз`).
3. Ветвление и сенсоры бортового компьютера (`если ... то`).
4. Условные циклы (`пока ... выполнить`).
5. Комбинирование конструкций и итоговое повторение.

## Технологии
- **Frontend**: HTML5, JavaScript (ES6+), Alpine.js, Tailwind CSS 4, DaisyUI 5.
- **PWA**: Service Worker, Web App Manifest, offline-кэширование, возможность установки на экран смартфона.

## Локальный запуск

Для запуска тренажёра на локальном компьютере достаточно любого статического веб-сервера:

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/pokedimon/CodeRulit.git
   cd CodeRulit
   ```

2. **Запустите локальный сервер (любым удобным способом):**
   - **Через Python 3:**
     ```bash
     python -m http.server 8000
     ```
   - **Через Node.js / npx:**
     ```bash
     npx serve .
     ```
   - **Через VS Code:** установите расширение *Live Server* и нажмите **Go Live**.

3. **Откройте приложение в браузере:**
   Перейдите по адресу `http://localhost:8000` (или порту, указанному сервером).
